# Responsible security testing and disclosures

**Current status:** OpenTrust is in pre-prototype development and is not a security product ready for production use.

## Authorized use only

Assess only systems you own or have explicit permission to test. Never run security checks against third-party services or production organizations without authorization.

## Test data

Use synthetic documents, fictional identifiers, and isolated test fixtures. Do not upload credentials, access tokens, financial records, identity documents, or personal information.

## Reporting a vulnerability

Do not publish working exploits against real affected organizations in issues. Contact the maintainer through GitHub privately where possible and provide a minimal, redacted reproduction. A dedicated private reporting workflow may be enabled as the project matures.

## No security guarantee

A passing OpenTrust assessment will not establish that a system is fully secure, compliant, or safe. Test coverage and limitations must accompany findings.
